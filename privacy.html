JobTrail HK

Privacy Policy

Last updated: 23 October 2026

This policy describes the JobTrail HK job-tracking application and this public information site. The application is being prepared for public launch; Gmail API integration is not yet deployed.

Information processed

  • Account information: email address, password hash, verification status, and authentication, verification and password-reset records. Passwords are stored as hashes rather than readable passwords.
  • Job-search content you provide: job titles, companies, links, application status, dates, notes, descriptions and cover-letter text.
  • Documents submitted for text extraction: PDF or DOCX content and filenames are processed to return extracted text. The extraction endpoint does not itself save a job record; content you subsequently save becomes part of your stored records.
  • Technical information: session and CSRF cookies, request information such as IP addresses, and operational or error logs. Hosting providers may also process request metadata.

Why information is used

To provide accounts and job-tracking features, process requested imports and documents, send account-related emails, protect access, diagnose failures and respond to support requests.

Google account authorization and email

The planned Gmail API integration requests only the gmail.send permission for the operator's JobTrail sender account. It is used to send verification, password-reset and requested account-support emails. It does not request permission to read the sender's inbox. Website users receiving these messages do not need to authorize their own Gmail accounts.

OAuth access and refresh tokens are sensitive credentials used by the server to send authorized messages. They are not intended to be exposed through this public website or its repository. Until the API integration is deployed, account emails use Gmail SMTP.

JobTrail HK's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold or used for advertising or AI model training.

Service providers and external websites

Google processes account emails and email delivery. The application uses PostgreSQL for stored records; the development database is hosted by Neon. Hosting and database providers process data needed to operate their services. This public information site is hosted on GitHub Pages when enabled. Production hosting details will be updated before public launch.

Requested job-link previews may contact supported external job websites, which receive the requested URL and server request metadata. Opening external links is subject to those websites' own privacy policies.

Retention and deletion requests

Saved records are kept to provide the service until removed or no longer needed. Session, verification and reset records have validity limits, but expiration does not by itself guarantee immediate deletion of all database or log copies. Backup and provider retention may differ.

Contact jobtrialhk@gmail.com to request access, correction or deletion of your account and associated information. The operator may need to verify account ownership before acting. No automatic deletion deadline is promised by this policy.

Security and choices

Do not upload unnecessary sensitive information. Keep your account credentials private. No internet service can guarantee absolute security. You can stop using the application, remove records through available controls, or contact the operator. The sender account owner can revoke Google authorization through Google Account settings, which prevents further authorized email sending until access is restored.

Changes and contact

This policy will be updated when data handling or providers change. Contact: jobtrialhk@gmail.com.
